PHISHAWARE
Created by Anjolaoluwa Donna Dosu

HOW TO OPEN:
1. Unzip this folder.
2. Open the "phishaware" folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Keep index.html, style.css, and app.js together in the same folder.

FEATURES:
- Responsive cybersecurity website
- Home, About Me, Technology, Cybersecurity, Threat Model, and Email Analyzer sections
- "Can You Spot the Phish?" activity
- 5-question cybersecurity quiz
- Phishing risk checker
- STRIDE threat model
- Educational phishing email analyzer
- PhishAware chatbot/assistant
- Microphone-style prototype interaction
- Achievement badges and progress tracking

IMPORTANT:
The email analyzer is an educational, local keyword-based demonstration. It is not a real AI security scanner.
